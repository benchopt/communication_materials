🚀 Exciting News: Benchopt v1.8 is officially here!

We are thrilled to announce the latest release of benchopt, making 𝗿𝗲𝗽𝗿𝗼𝗱𝘂𝗰𝗶𝗯𝗹𝗲 𝗼𝗽𝘁𝗶𝗺𝗶𝘇𝗮𝘁𝗶𝗼𝗻 𝗮𝗻𝗱 𝗺𝗮𝗰𝗵𝗶𝗻𝗲 𝗹𝗲𝗮𝗿𝗻𝗶𝗻𝗴 𝗯𝗲𝗻𝗰𝗵𝗺𝗮𝗿𝗸𝘀 faster and more flexible than ever.

This version brings significant improvements to how you run, visualize, and scale your benchmarks. Here are the highlights:

* 𝗜𝗺𝗽𝗿𝗼𝘃𝗲𝗱 𝗗𝗼𝗰𝘂𝗺𝗲𝗻𝘁𝗮𝘁𝗶𝗼𝗻: New guides on running ML benchmarks and the ability to run benchmarks directly as examples in the documentation.
* 𝗗𝗶𝘀𝘁𝗿𝗶𝗯𝘂𝘁𝗲𝗱 𝗖𝗼𝗺𝗽𝘂𝘁𝗶𝗻𝗴: We’ve introduced a new parallel backend system for benchopt run. You can now easily set up distributed runs using Dask and Submitit.
* 𝗖𝘂𝘀𝘁𝗼𝗺 𝗣𝗹𝗼𝘁𝘁𝗶𝗻𝗴: Benchmarks are no longer limited to default views! You can now create custom plots tailored to your specific research needs.
* 𝗔𝗣𝗜 𝘀𝗶𝗺𝗽𝗹𝗶𝗳𝗶𝗰𝗮𝘁𝗶𝗼𝗻𝘀: We also made several API improvements to enhance usability and streamline your workflow.
