🚀 We’ve just released Benchopt 1.7 — our open-source framework for benchmarking ML algorithms!

✨ Highlights of this release:

* Simplification in the API — Creating a new benchmark has never been this easy (no more safe_import_context 🎊).
* API improvements: better handling of requirements, SLURM configuration, and richer result DataFrames.
* New CLI features: improved options to control the run of a benchmark.
* Windows support 🎉 — Benchopt now runs natively on Windows, broadening accessibility.

+ Many fixes and quality-of-life improvements for a smoother user experience.
